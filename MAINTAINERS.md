## Note on Single-Maintainer Status

FluxGate is currently maintained by one person. This is worth stating clearly:

* Pull request reviews happen on a best-effort basis, typically within one to
  two weeks for straightforward changes.
* Critical security fixes are prioritised and addressed within the timeframe
  described in [SECURITY.md](SECURITY.md).
* Releases follow the cadence described in [GOVERNANCE.md](GOVERNANCE.md).

If you depend on FluxGate in a production system, consider contributing back so
that maintenance burden is shared. See [CONTRIBUTING.md](CONTRIBUTING.md).
